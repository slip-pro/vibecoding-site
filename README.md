# Вайбкодинг — сайт курсов

Сайт двухчастного курса по созданию сайтов с AI от команды [kkts.ai](https://kkts.ai).

## Используется в курсе Часть 2

Этот репозиторий — **стартовый шаблон** для курса "Профессиональный AI-workflow".
Если у тебя нет сайта из Части 1 — клонируй этот репо и начни с него.

## Быстрый старт

```bash
# Клонировать
git clone https://github.com/kkts-ai/vibecoding-site
cd vibecoding-site

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000) в браузере.

## Docker

```bash
docker compose up --build
```

## Стек

- **Next.js 16** (App Router)
- **Tailwind CSS 4**
